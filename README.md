# Voynich decoding findings

Four rounds of computational attempts to decode the Voynich manuscript (Beinecke MS 408), October 2026. **No translation was found**; the site summarises what was tested and what the text turned out to be like.

- Site: https://jad-deeb.github.io/voynich-findings/ (`index.html`, published with GitHub Pages)
- Reports: `Voynich_Research_Notes.md`, `Voynich_Decoding_Attempt_2.md` to `_4.md`
- Code and results: `Voynich_Decoding_Research_2/`, `Voynich_Decoding_Research_3/` (also packed in `voynich-research-code-and-results.zip`)

Third-party data (transliterations, corpora, model outputs) is not redistributed; the scripts download it. Sources and licences are listed on the site and in the reports.
